# E-Commerce Data Analysis & Dashboard

## Overview
End-to-end data analysis project on an e-commerce dataset involving cleaning, analysis, and visualization using Python.

## Objective
To extract meaningful business insights from raw retail transaction data.

## Dataset
Online retail dataset containing product details, transactions, and customer information.

## Features
- Data cleaning and preprocessing
- Handling missing values and duplicates
- Feature engineering (Revenue, Month)
- Top product analysis
- Country-wise sales analysis
- Monthly revenue trends
- Customer behavior analysis

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## Workflow
1. Load raw dataset
2. Clean and preprocess data
3. Create new features
4. Perform exploratory data analysis
5. Generate visualizations
6. Build dashboard

## Key Insights
- Top revenue-generating products identified
- Highest contributing countries found
- Monthly sales trends analyzed
- Known vs unknown customer behavior compared

## Dashboard
Interactive Streamlit dashboard for exploring insights.

## How to Run
Install dependencies:
pip install -r requirements.txt

Run dashboard:
streamlit run dashboard.py
